# Salesman_Score_Prediction_Project
A machine learning model that predicts salesman performance scores using historical sales data helping businesses identify top performers and optimize their sales force.
## Technologies Used
- Python
- NumPy
- Pandas
- Scikit-learn
- matplotlib
- seaborn

## Project Files
- sellerpass.py
- dresspred.ipynb
- model.sav
- preprocessing.sav files

## How to Run
1. Clone the repository
2. Install required libraries
3. Run the Python file:
   streamlit run sellerpass.py
